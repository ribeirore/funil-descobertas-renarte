# Renarte Briefing

Demonstração front-end do funil de briefing para encomendas de pinturas Renarte.

## Conteúdo

`index.html` é a demonstração pronta para publicação em hospedagem estática. `App.tsx` contém a versão React com hooks, Tailwind CSS e Lucide React. `Logo-Renarte-SemFundo.png` é o logo usado no cabeçalho.

## Deploy na Vercel

Importe este repositório na Vercel como um projeto estático. Não é necessário configurar build command ou output directory para a demonstração HTML. O arquivo de entrada é `index.html`.

## Configuração do WhatsApp

Antes de publicar, substitua `SEUNUMERO` pelo número real em formato internacional, sem o sinal de mais, espaços ou símbolos, tanto no `index.html` quanto no `App.tsx`.

## Escopo atual

O upload funciona somente no front-end. Os nomes dos arquivos são mantidos no estado do formulário e aparecem no resumo. Nenhuma imagem é enviada para um backend nesta versão.
